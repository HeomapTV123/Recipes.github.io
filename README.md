# Recipes.github.io
How to run the repository:
clone the git respository
https://github.com/HeomapTV123/Recipes.github.io.git

install dotenv in your terminal:
npm install dotenv

create a .env file with your credentials:
PORT=your_port
host=localhost (example)
user=root (example)
password=your_password
database=your_database
SESSION_SECRET=your_super_secret_key

Go to your web browser and type in
http://localhost:your_port
and you should see the main page
